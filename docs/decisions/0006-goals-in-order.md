# 0006 ゴールを重要順に決め、ぶつかったら上を取る

- 状態: 採用

## 背景

「必ず届ける」と「値を出さない」「部屋をうるさくしない」は、ぶつかることがある。直すたびに判断がぶれないよう、順番を決めておく。

## 選んだ物

[README](../../README.md#ゴール重要順) の 7 つのゴールを重要順に並べ、ぶつかったら上を取る。

| ぶつかる場面 | 決め方 |
| --- | --- |
| 伏せる処理に失敗した（1 と 2） | その項目だけ省き、知らせは送る |
| 本文の組み立てに失敗した（1 と 2・3） | 値を含まない最小の知らせを送る |
| 同じ例外が続く（1 と 6） | 間引き、送らなかった回数を次の知らせに書く。元の例外はどれもログにある |

## 選ばなかった物

ゴールを並べずに、場面ごとに判断する。判断の根拠が残らず、直す人によってぶれる。

## 代償

下のゴールは、上のゴールのために我慢することがある（例: 最小の知らせは種類が分かりにくい）。
