# 0009 送り先の部屋の分け方は部品の前提にしない

- 状態: 採用

## 背景

送り先の部屋は、複数のアプリの例外をまとめて受けることがある。形の無い個人情報（氏名など）は伏せきれないので、部屋に入る人によっては見えてはいけない物が見える。

## 選んだ物

部屋の分け方は使う側で判断する。部品は、部屋が共用でも秘密と形の分かる個人情報が出ないことを守る（[0007](0007-message-by-kind.md)）。

## 選ばなかった物

部屋をアプリごとに分けることを部品の前提にする。部屋の運用は使う側の事情で決まり、部品からは強制できない。

## 代償

部屋が共用なら、`send_message` で送った文言の中の形の無い個人情報は、ほかのアプリの担当にも見える。それを避けたいなら、部屋を分けるか、`send_message` を false のままにする。
