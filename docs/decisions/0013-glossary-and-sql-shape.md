# 0013 番号に決まった日本語を添え、DB の例外は値を ? にした SQL の形を出す

- 状態: 採用（0007 の延長。0007 の「元の文言は使わない」は変えない）

## 背景

知らせには SQLSTATE・ドライバーの番号・HTTP の状態・Google の reason・終了コードが出るが、意味は出ていなかった。ドライバーの文言が許可リストの外なら、メッセージは `SQLSTATE[22003] ドライバー 1264（文言はログ）` のように番号だけになり、何が起きたかを知るには番号を調べ直す必要があった。

DB の例外は SQL を「（ログ）」に置き換えていたので、どの表のどの操作で起きたかも知らせだけでは分からなかった（ゴール 2）。値を埋めた SQL を出せば分かりやすいが、メールアドレス・IP・トークンなどの値まで部屋に出る（ゴール 3・4）。

## 選んだ物

- 番号・SQLSTATE・状態・reason・終了コード・一部の例外のクラスに、決まった日本語を表から引いて足す（`Glossary`）。件名には短い言葉、本文にはメッセージの枠の後ろに「説明: 」の行
  - 引く順は、MySQL・MariaDB の接続なら MySQL の番号 → SQLSTATE（完全一致）。HTTP は Google の reason → 状態
  - 表に無い値には何も足さない。SQLSTATE の頭 2 文字で推測しない
  - 原因を断定しない。根拠は公式の資料（MySQL・ODBC・PostgreSQL・RFC・Google・Bash）と vendor のコード
- 件名の要約を「短い言葉・決まった項目・番号」の順にする。件名は後ろから切るので、切れるときは番号から落ちる（番号は本文の枠に残る）
- DB の例外（MySQL・MariaDB の接続）では、値を `?` にした SQL の形を別の `[code]` の枠に出す（`SqlShape`）
  - 元は値を埋める前の `getSql()`。部品が字句を読み、許可リストの字句（名前の文字だけのバッククォートの識別子・SQL のキーワードと関数・`?`・記号）だけを残し、ほかはすべて `?` にする。元の文言は使わず、部品が組み立て直す（0007 の延長）
  - 接続の設定のデータベース名は `{db}` にする
  - 読む長さ・出す幅に上限を置き、並びを縮める。組み立てに失敗したら形を出さず、今までどおり `SQL: （ログ）`
- ドライバーの文言の許可リストに、値を含まない形を足す（1264・1364・1205・1213）
- 版は 0.6.0（件名の並び・`Details::of()` の要約・README の「送らないもの」が変わるため。[0003](0003-name-and-versioning.md)）

規則は [redaction.md](../redaction.md#sql-の形)、本文の形は [message-format.md](../message-format.md)。

## 選ばなかった物

| 案 | 選ばなかった理由 |
| --- | --- |
| 表名と操作（`insert into employees` など）だけを出す | どの列・どの条件かが分からず、知らせだけで判断しにくい |
| 値を埋めた SQL（`getRawSql()`）を伏せる規則で出す | どんな値でも来うる文字列に対して、伏せる規則では「これで全部」と言えない（0007 と同じ理由） |
| 引用符の無い語も残す | `whereRaw("token = {$token}")` のように埋めた値が残る。許可リストの語だけ残す |
| すべてのドライバーで形を出す | PostgreSQL の `$$…$$` などの引用の形を読み違えると、中身が語として残る。対応は別に足す |
| SQLSTATE の分類（頭 2 文字）で説明する | 42 は構文と権限が混ざるなど、外れたときに誤った案内になる |
| 表に無い 4xx・5xx に「相手が拒否」「相手のエラー」を付ける | 「知らない値には何も付けない」に反する |

## 代償

- SQL の形には表名・列名などの名前が残る。識別子に利用者の入力を入れた書き方（`orderBy($request->sort)`）で名前の文字だけの値、接続の設定と違うデータベースの名前、テナントごとの表名は、そのまま部屋に出る（README の「伏せきれない物」）
- raw で引用符なしに書いた列名や、許可リストに無い関数は `?` になる
- 長い insert の列名は幅 600 で切れる
- 件名で知らせを見分けている仕組み（Chatwork の検索・転送の規則など）は、件名の並びが変わるので直す必要がある
