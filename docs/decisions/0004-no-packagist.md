# 0004 Packagist に登録しない

- 状態: 採用

## 背景

Packagist に登録すると、登録したアカウントが部品の管理者になり、GitHub との自動更新もその人の権限で動く。管理者と自動更新を持ち続ける手間をかけたくない。

## 選んだ物

登録しない。使う側は composer.json に GitHub のリポジトリを書いて入れる（公開なので鍵は要らない）。書き方は [README](../../README.md#入れ方)。

## 選ばなかった物

| 案 | 選ばなかった理由 |
| --- | --- |
| 個人のアカウントで登録 | 管理者がその人に結び付き、引き継ぎが要る |
| 既存の部品と同じ登録者 | 登録者と手順を揃える手間がかかる |

## 代償

使う側が `repositories` を書く。Packagist の検索には出ない。
