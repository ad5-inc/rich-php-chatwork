# 0005 例外の文言は既定で送らない

- 状態: 置き換え（[0012](0012-always-send-message.md)）

## 背景

例外の文言には、値を埋めた SQL・メールの宛先・接続先・トークンなどが入りうる。一方で、文言が無いとどんな例外かが分かりにくい。

## 選んだ物

- 既定では、形の分からない例外の文言を送らない（`send_message` が false）
- 送るかどうかは使う側で判断する。送るのは、送り先の部屋に入る人が文言を見てよいと決めたときだけ
- 送るときも、形のある秘密と個人情報は伏せる（[redaction.md](../redaction.md)）
- 形の分かる例外（DB・HTTP クライアント）は、設定に関係なく部品が組み立て直した文言を送る（[0007](0007-message-by-kind.md)）
- 文言が無くても種類が分かるよう、件名に値を含まない要約を出す

## 選ばなかった物

| 案 | 選ばなかった理由 |
| --- | --- |
| いつも送る | 値・秘密が部屋に出る |
| 送る例外を一覧で指定する | 一覧を保つ手間がかかり、後から値を含む例外が混ざる |
| いつも送らない | 文言が無いと種類が分かりにくい |

## 代償

`send_message` を true にすると、氏名のような形の無い個人情報は伏せきれずに出る。

> 注記: 後の版で、形の分かる例外に外のコマンド（Laravel・Symfony の Process）の例外も加えた（[redaction.md](../redaction.md#組み立て直す例外)）。
