# 0001 PHP 8.5 / Laravel 13 だけに対応する

- 状態: 採用

## 背景

入れる予定のアプリは PHP 8.5 / Laravel 13。古い版のアプリに入れる予定は無い。

## 選んだ物

`"php": "^8.5"`、`illuminate/*` は `^13.0`。CI は 1 通り。

## 選ばなかった物

| 案 | 選ばなかった理由 |
| --- | --- |
| PHP 8.2 / Laravel 10 以上 | 新しい書き方が使えない。CI が版の組み合わせの行列になる |
| PHP 8.3 / Laravel 12 以上 | 使う予定の無い版のために行列を持つことになる |

## 代償

古い版のアプリには入らない。入れたくなったら、その時に版を下げる（下げるのは上げるより手間がかかる）。
